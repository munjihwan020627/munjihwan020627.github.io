# Moon Jihwan Portfolio

GitHub Pages용 정적 포트폴리오입니다.

## 배포
1. GitHub에서 `munjihwan020627.github.io` 저장소를 생성합니다.
2. 이 폴더의 `index.html`, `styles.css`, `script.js`를 저장소 최상위에 업로드합니다.
3. Repository → Settings → Pages에서 `Deploy from a branch`, `main`, `/ (root)`를 선택합니다.
4. 잠시 후 `https://munjihwan020627.github.io`에서 확인할 수 있습니다.

## 수정 포인트
- 이메일을 공개하려면 `index.html` Contact 영역에 추가하세요.
- 이력서 PDF를 추가하려면 파일명을 `resume.pdf`로 두고 버튼 링크를 `resume.pdf`로 연결하면 됩니다.
- 프로젝트 스크린샷을 추가하면 포트폴리오 완성도가 더 높아집니다.
